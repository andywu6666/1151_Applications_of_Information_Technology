# 1151 資訊科技應用｜Applications of Information Technology

本 repository 用於整理 115 學年度第 1 學期「資訊科技應用」課程的小組資料，包含各組員的研究與實作內容、論文參考範本、每週進度報告，以及開會照片。

## 資料夾結構

以下為預計採用的目錄結構。

```text
1151_Applications_of_Information_Technology/
├── Chan/
│   └── reference_papers/
├── Lin/
├── Wu/
│   └── reference_papers/
├── Zhao/
├── Su/
├── weekly_reports/
├── photos/
└── README.md
```

## 資料夾說明

| 資料夾 | 內容說明 |
| --- | --- |
| `Chan/` | Chan 的個人研究、實作與相關資料。 |
| `Lin/` | Lin 的個人研究、實作與相關資料。 |
| `Wu/` | Wu 的個人研究、實作與相關資料。 |
| `Zhao/` | Zhao 的個人研究、實作與相關資料。 |
| `Su/` | Su的個人研究、實作與相關資料。 |
| `weekly_reports/` | 每週進度報告檔案，用於記錄小組的工作進展與成果。 |
| `photos/` | 小組開會照片與討論過程紀錄。 |

### 論文參考範本

`Chan/reference_papers/` 與 `Wu/reference_papers/` 收錄過去製作的論文，作為本次論文撰寫與製作時的參考範本，例如章節安排、內容組織及排版方式。

### 每週進度報告

`weekly_reports/` 集中存放各週的進度報告，方便組員查閱、追蹤工作進展及回顧討論內容。

### 開會照片

`photos/` 集中存放小組開會照片，作為課程討論與合作過程的紀錄。
